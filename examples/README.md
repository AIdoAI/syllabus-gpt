## How to Use

1. **Test Syllabus-GPT:**
   - Upload this PDF to Syllabus-GPT
   - Click "Process Documents"
   - Try asking questions like:
     - "What is the grading breakdown?"
     - "When is the midterm exam?"
     - "What are the prerequisites?"
     - "What is the late submission policy?"
     - "What topics are covered in week 8?"

2. **Verify Source Citations:**
   - Each answer should include citations showing the exact page number
   - Example: `📄 CS301_AI_Syllabus.pdf (p. 1)` or `(p. 3)`

3. **Test Multiple Documents:**
   - Add your own course PDFs alongside this sample
   - See how Syllabus-GPT handles multiple documents
